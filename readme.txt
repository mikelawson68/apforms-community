Build forms, collect entries, and send notifications from your WordPress site.

== Description ==

Use the visual builder to create forms with common field types, confirmations, email notifications, entry management, and CSV export. Forms and entries are stored on your site.

The free plugin works independently. The separately distributed apForms Pro add-on provides conditional logic, file uploads, and optional AI tools. An existing form that uses Pro fields requires the add-on to remain active.

== Installation ==

1. Upload and activate apForms.
2. Create a form under apForms > New Form.
3. Add its shortcode to a page and configure notifications if needed.
